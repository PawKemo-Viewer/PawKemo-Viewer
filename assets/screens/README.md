# スクリーンショット

`{言語}-{テーマ}-{画面}-{端末}.png` が紹介サイトと Wiki の共通画像です。

- 言語は `ja` と `en`、テーマは `light` と `dark`、端末は `desktop` と `mobile` です。
- 画面は `home`、`creators`、`following`、`detail`、`settings` です。
- 現在の画像は 0.5.7 の製品版 UI をサンプルデータで撮影しています。
- Wiki では公開サイトの `assets/screens/` の URL を使います。更新時は同じファイル名で差し替えると、紹介サイトと Wiki の両方に反映されます。

個別の設定カテゴリは "ja-light-settings-{カテゴリ}-{端末}.png" に保存します。画像名は Wiki の設定ページと今後の紹介サイトから同じ URL で参照できます。
